# Online Softmax：流式归一化统计

实现普通 CPU 算法，可选择 C++17 或 Python 标准库；不需要 GPU、CUDA、PyTorch 或 NumPy。

普通稳定 Softmax 先求整段输入的最大值，再计算指数和。本题的数据按块到达，处理当前块时看不到历史输入，只能使用此前保存的两个标量：

- `running_max`：已处理数据的最大值 `m`。
- `running_sum`：以该最大值为基准的指数和 `l = Σ exp(x_i - m)`。

请实现 `online_softmax_update(running_max, running_sum, chunk)`，返回合并当前块后的 `(new_max, new_sum)`。初始状态为 `(-∞, 0)`；空块必须保持状态不变。已有非空历史的状态也可能直接作为函数输入，请勿假设第一次调用一定是空历史。

## 在线更新

每读入一个数 `x`，更新：

```text
new_max = max(m, x)
new_sum = l * exp(m - new_max) + exp(x - new_max)
```

新最大值出现时，必须重缩放此前累积的指数和。由于输入都是有限数，初态读入首个元素后得到 `(x, 1)`；空块不能计算 `-∞ - (-∞)`。

也可以先计算当前块的稳定统计，再用相同的缩放规则合并两组统计。不允许缓存历史数据或依赖跨调用的隐藏状态。要求处理一个块的时间复杂度为 `O(len(chunk))`、额外空间为 `O(1)`；判题会验证数值与跨块语义，但黑盒测试不等同于空间复杂度证明。

## 与 Softmax 输出的关系

本题返回的是 Online Softmax 的核心归一化统计，**不是当前块的概率，也不是完整概率数组**。全部数据到达后，最终概率为：

```text
p_i = exp(x_i - final_max) / final_sum
```

如果需要输出所有概率，还需要保留原输入或再次读取数据。判题器会保留输入，在每个块后检查统计，并在最后第二遍验证归一化概率；你的函数只接收当前块和两个统计量。

## 示例

依次输入 `[1, 2]`、空块、`[3, 0, -1]`：

1. `update(-∞, 0, [1, 2]) ≈ (2, 1.3678794412)`。
2. 空块后状态不变。
3. `update(2, 1.3678794412, [3, 0, -1]) ≈ (3, 1.5713174317)`。

最终对应 `[1, 2, 3, 0, -1]` 的概率约为 `[0.0861285, 0.2341217, 0.6364086, 0.0316849, 0.0116562]`。已有累计量为任意合法历史的状态也应正确合并。

## 约束与判题

- 总元素数 `0 ≤ N ≤ 131072`；元素为有限双精度数，范围 `[-10000, 10000]`。
- 分块长度可为零；覆盖单元素分块、随机分块、反复更新最大值、极端值、全等数据、已有历史状态和长序列。
- 不得修改 `chunk`；不得执行完整 Softmax 后用局部概率替代累计统计。
- 非空状态必须有限且指数和为正；空状态保留负无穷最大值和零指数和。
- 统计与概率使用 `atol=1e-9, rtol=1e-9` 比较。输入没有 NaN 或正负无穷，唯一允许的无穷是空初态的最大值。
- 模板是可运行的正确基线，便于直接验证流程；可在此基础上练习重写或优化。

## 性能统计

使用 CPU 单调高精度时钟，每个样本处理一整条分块输入流；包括函数调用和在线更新，不包括生成输入、分块、参考答案与验证。预热 2 次、采样 7 次。C++ 与 Python、不同 CPU 或不同运行环境的结果应分别比较，不能与 GPU Event 延迟直接比较。

算法背景：[Online normalizer calculation for softmax](https://arxiv.org/abs/1805.02867)。
