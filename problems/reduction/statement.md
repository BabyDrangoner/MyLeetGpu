# 单精度向量求和归约

给定一个长度为 `n` 的单精度浮点向量，请在 GPU 上求出所有元素之和，并将结果写入 `output[0]`。

## 接口

只实现下面的 `solve`，不要提供 `main`：

```cpp
void solve(
    const float* input,
    float* output,
    int n,
    cudaStream_t stream);
```

`input` 指向含有 `n` 个元素的设备内存，`output` 指向一个可写的设备端 `float`。二者不重叠。`n` 在 `1` 到 `16,777,216` 之间，输入是 `[-1, 1]` 内的有限值。

每次调用都必须独立产生完整结果，不能依赖 `output` 原来的内容。所有 kernel、memset 或异步操作都必须使用传入的 `stream`；函数返回前无需同步。

## 正确性

参考结果在 CPU 上以双精度累加，再转换为单精度。由于并行归约的加法顺序不同，允许以下误差：

```text
abs(actual - expected) <= 0.02 + 0.00005 * abs(expected)
```

NaN 不通过验证，无穷值只有在与参考结果同号时才相等。公开样例覆盖单元素和抵消模式，完整验证还会使用非二次幂长度、常量输入与固定种子的正负随机输入。

## 性能说明

计时由平台控制。CUDA 上下文初始化、测试数据生成、设备内存分配和数据拷贝都发生在计时区间之外；预热后，每个样本由同一 stream 上的 CUDA Events 包围多次 `solve` 调用，并折算为单次耗时。若实现采用原子累加，请确保每次调用都会先在该 stream 上正确初始化输出。
