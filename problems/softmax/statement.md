# 二维张量逐行 Softmax

输入是一个按行主序连续存放的 `rows x cols` 单精度浮点矩阵。请在 GPU 上对每一行独立计算 Softmax：

```text
row_max = max(input[row, :])
output[row, col] = exp(input[row, col] - row_max)
                 / sum_j(exp(input[row, j] - row_max))
```

减去行最大值是题目要求的数值稳定形式。每行的输出都应为非负有限值，且总和约等于 1。

## 实现约束

只实现平台约定的 `solve`，不要提供独立程序入口。`input` 和 `output` 是 GPU 上互不重叠、按行主序连续存放的 `float32` 一维缓冲区；`input` 为只读，调用后内容必须保持不变。`rows` 至少为 1、至多为 65,536；`cols` 至少为 1、至多为 4,096；元素总数不超过 16,777,216。输入是 `[-100, 100]` 内的有限值。

平台预先分配输入和输出，并控制执行 stream。实现必须把工作提交到平台选择的当前 stream，写入已有的 `output`，且不应在返回前执行设备级同步。所选语言的确切函数签名和调用规则见题面末尾的语言说明。

## 正确性

公开样例包含单元素行和列数不是 2 的幂的矩阵。完整验证还会覆盖随机值、大小差异显著的极端值、每行重复值、很宽的行以及非规整尺寸。结果按浮点容差比较。内部用例由固定种子生成，执行结果可复现，但失败输出不会暴露其输入。

## 性能说明

平台会在计时前创建 CUDA 上下文、生成并上传输入、分配内存和执行预热。每个样本在同一条 stream 上计时若干次 `solve`，报告值会除以重复次数。可以关注逐行最大值和求和归约、指数计算次数、合并访存，以及不同行宽下的并行度。
