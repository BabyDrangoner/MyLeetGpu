# 单精度向量最大值归约

给定一个长度为 `n` 的单精度浮点向量，请在 GPU 上找出其中的最大值，并将结果写入 `output[0]`。

## 实现约束

只实现平台约定的 `solve`，不要提供独立程序入口。`input` 是 GPU 上含有 `n` 个 `float32` 元素的只读连续一维缓冲区，调用后内容必须保持不变；`output` 是 GPU 上含有一个可写 `float32` 元素的缓冲区，二者不重叠。`n` 在 `1` 到 `16,777,216` 之间，输入可以是任意有限 `float32` 值。

每次调用都必须独立产生完整结果，不能依赖 `output` 原来的内容。平台控制执行 stream；所有 kernel、输出初始化和其他异步操作必须使用平台选择的当前 stream，函数返回前无需同步。所选语言的确切函数签名和调用规则见题面末尾的语言说明。

## 正确性

输出必须与输入中最大的 `float32` 值完全相等，不允许使用近似误差。验证数据包含单元素向量、全负数、有符号零、接近 `float32` 范围边界的值、非二次幂长度、正负交替值与固定种子的随机输入。

## 性能说明

计时由平台控制。CUDA 上下文初始化、测试数据生成、设备内存分配和数据拷贝都发生在计时区间之外；预热后，每个样本由同一 stream 上的 CUDA Events 包围多次 `solve` 调用，并折算为单次耗时。若实现采用多 block 原子归约，请确保每次调用都会先在该 stream 上正确初始化输出。
