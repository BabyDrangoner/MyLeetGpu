# 行主序矩阵乘法

给定按行主序连续存放的两个单精度浮点矩阵 `A` 和 `B`，其形状分别为 `m x k` 与 `k x n`。请在 GPU 上计算矩阵乘积 `C = A @ B`，并将结果写入同样按行主序存放的 `m x n` 输出矩阵：

```text
C[row, col] = sum(A[row, inner] * B[inner, col], inner=0..k-1)
```

## 实现约束

只实现平台约定的 `solve`，不要提供独立程序入口。`A`、`B`、`C` 是 GPU 上互不重叠、连续存放的 `float32` 一维缓冲区；需要根据题目给出的形状按行主序解释它们。`A` 和 `B` 为只读，调用后内容必须保持不变。题目不包含 bias，也不需要转置任何矩阵。

`m`、`k`、`n` 均至少为 1、至多为 4096，且三个矩阵各自的元素数均不超过 16,777,216。输入是 `[-1, 1]` 内的有限值。平台预先分配输入和输出，并控制执行 stream；实现应写入已有的 `C`，且不应在返回前执行设备级同步。所选语言的确切函数签名和调用规则见题面末尾的语言说明。

## 正确性

浮点乘加的结合顺序可能因 tile、warp 和硬件而不同，平台会使用绝对误差 `0.03`、相对误差 `0.005` 检查结果。公开样例是便于手算的非方阵；完整验证还会覆盖维度不是常用 tile 整数倍的矩阵、`m=1` 或 `n=1` 的瘦矩阵、达到单维上限的薄矩阵、较大的归约维度以及宽矩阵。内部用例由固定种子生成，执行结果可复现，但失败输出不会暴露其输入。

## 性能说明

平台会在计时前创建 CUDA 上下文、生成并上传输入、分配内存和执行预热。每个样本使用同一条 stream 上的一对 CUDA Events，只包围若干次 `solve`；报告值会除以重复次数。可考虑二维分块、共享内存、合并访存、寄存器复用以及归约维度的 tile 大小。
