# 二维张量逐行 Top-K

输入是一个按行主序连续存放的 `rows x cols` 单精度浮点矩阵。请在 GPU 上对每一行独立选出最大的 `k` 个元素，并写入两个按行主序存放的 `rows x k` 输出：

- `values[row, rank]` 是第 `row` 行第 `rank` 大的值，每行必须按非递增顺序排列。
- `indices[row, rank]` 是该值在输入行中的列索引，必须满足 `values[row, rank] == input[row, indices[row, rank]]`。

同一行输出的索引必须合法且互不相同。当多个元素值相同时，这些元素之间的顺序不作要求；如果并列值跨过 Top-K 边界，选择其中任意合法索引都会被接受。

## 实现约束

只实现平台约定的 `solve`，不要提供独立程序入口。`input`、`values` 和 `indices` 都是 GPU 上互不重叠的连续缓冲区。`input` 为只读，调用后其位内容必须保持不变。

`rows >= 1`，`1 <= cols <= 1024`，`1 <= k <= min(cols, 64)`，且 `rows * cols <= 4,194,304`。输入是 `[-10000, 10000]` 内的有限 `float32` 值。

平台预先分配输入和输出，并控制执行 stream。实现必须将工作提交到平台选择的当前 stream，覆盖写入两个已有输出，不能依赖输出原有内容，且不应在返回前执行设备级同步。所选语言的确切函数签名和调用规则见题面末尾的语言说明。

## 正确性

公开样例覆盖 `k = 1`、非 2 的幂行宽和重复值。完整验证还会覆盖 `k = cols`、大量短行、宽度 1,024、接近元素数上限的矩阵及大量并列值。验证会同时检查值、顺序、索引及输入不变性，并在不同输出毒化值下重复调用。

## 性能说明

平台会在计时前创建 CUDA 上下文、生成并上传输入、分配内存和执行预热。每个样本在同一条 stream 上计时若干次 `solve`，报告值会除以重复次数。可以关注每行候选集的排序/选择成本、合并访存，以及在不同 `cols` 和 `k` 下的并行度。
